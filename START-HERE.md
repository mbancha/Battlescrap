# Moonfall Tactics
[Play](https://mbancha.github.io/Moonfall-Tactics/) · [Repository](https://github.com/mbancha/Moonfall-Tactics)

Read [README.md](README.md) for authoritative sources and commands. The [Sol plan](planning/build-spec-current.txt) specifies the current digital target; [ARCHITECTURE.md](ARCHITECTURE.md) describes the local code and [VERIFICATION.md](VERIFICATION.md) records evidence.

Current print files are in [print-and-play/current](print-and-play/current). Current portrait masters are in assets/heroes/current, element masters in assets/print/icons, and equipment art in assets/equipment. The live sheet owns playable availability and content.

Install with npm ci and run npm run dev -- --host 127.0.0.1. On Windows use npm.cmd as needed.
